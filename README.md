# AIBA Sync // Campus Routine & Utility Platform

A blazing-fast, zero-friction, client-side campus utility and live academic routine terminal built specifically for **Army Institute of Business Administration (AIBA), Sylhet**.

## 🏛️ মূল সুবিধাসমূহ (Core Features)

1. **প্রিমিয়াম লাইট ও ডার্ক থিম (Light Mode Default)**:
   - ঝকঝকে ও পরিচ্ছন্ন অফিশিয়াল হোয়াইট ব্যাকগ্রাউন্ড ডিফল্ট হিসেবে রাখা হয়েছে। সাথে রয়েছে ডিপ ওবসিডিয়ান মিডনাইট-স্লেট ডার্ক মোড টগল।
2. **মার্জিত ও প্রফেশনাল ডিজাইন (Zero Childish Emojis)**:
   - কোনো অপ্রয়োজনীয় বা অনানুষ্ঠানিক ইমোজি নেই; সম্পূর্ণ ইন্টারফেসে মিলিটারিয়ান-একাডেমিক আভিজাত্যের সাথে ব্যবহার করা হয়েছে ক্রিস্প Lucide আইকন এবং ক্লিন ব্যাজ।
3. **বিবিএ-১১ মেজর ও মাইনর ইন্টিগ্রেশন (BBA-11 Major & Minor Logic)**:
   - সিনিয়র ব্যাচ (BBA-11) শিক্ষার্থীদের জন্য একই সাথে মেজর (`FIN`, `ACC`, `MKT`, `SCM`) এবং মাইনর (`MIS-M`, `HRM-M` বা `None`) সিলেক্ট করার পূর্ণ সুবিধা।
4. **ব্যক্তিগত অনবোর্ডিং ও ফর্মাল একাডেমিক সম্ভাষণ**:
   - শিক্ষার্থীর নাম দিয়ে ব্যক্তিগত ও মার্জিত প্রাতিষ্ঠানিক সম্ভাষণ।
5. **লাইভ স্ট্যাটাস রাডার (Live Status Card & Countdowns)**:
   - চলমান ক্লাসের জন্য লাইভ পালস ইন্ডিকেটর এবং শেষ হওয়ার নিখুঁত কাউন্টডাউন।
   - পরবর্তী ক্লাসের রুম এবং শুরু হওয়ার কাউন্টডাউন।
   - সব ক্লাস শেষ হলে প্রাতিষ্ঠানিক বার্তা এবং শুক্র/শনিবার সাপ্তাহিক ছুটির নোটিশ।
6. **ফ্যাকাল্টি ডিরেক্টরি পপওভার (Faculty Directory)**:
   - শিক্ষকের নামের ওপর ক্লিক বা ট্যাপ করামাত্র তার পুরো নাম, পদবি, বিভাগ এবং ফ্যাকাল্টি রুম নম্বর পপআপে ভেসে উঠবে।
7. **ফাঁকা রুম ডিটেক্টর (Empty Room Finder)**:
   - ক্যাম্পাসের ১৬টি রুমের মধ্যে কোন কোন রুম এই মুহূর্তে ফাঁকা এবং কতক্ষণ ফাঁকা থাকবে তা রিয়েল-টাইম ক্যালকুলেশন।
8. **একাডেমিক ক্যালেন্ডার (Official Fall 2026 Calendar)**:
   - মিডটার্ম, ফাইনাল পরীক্ষা, রেজিস্ট্রেশন ডেটলাইন ও সরকারি ছুটির দিনের সম্পূর্ণ প্রাতিষ্ঠানিক তালিকা।
9. **ডুয়াল ভিউ (Today Timeline vs. Full Week Grid)**:
   - আজকের দিনের টাইমলাইন কার্ড (পিরিয়ড ও বিরতি স্লটসহ) এবং পুরো সপ্তাহের কমপ্যাক্ট শিডিউল।
10. **হাই-কোয়ালিটি রুটিন ইমেজ এক্সপোর্ট**:
    - এক ক্লিকে ইনস্টাগ্রাম/হোয়াটসঅ্যাপ ফ্রেন্ডলি পার্সোনালাইজড রুটিন কার্ড PNG ইমেজ হিসেবে ডাউনলোড।
11. **অফলাইন PWA (Progressive Web App)**:
    - দুর্বল নেটওয়ার্ক বা ইন্টারনেট ছাড়াও অফলাইনে রুটিন দেখার পূর্ণ সক্ষমতা।

## 🚫 কঠোর নিয়ম (Zero Bloatware)

- কোনো CGPA ট্র্যাকার বা কাল্পনিক ক্যালকুলেটর নেই।
- কোনো অপ্রয়োজনীয় স্টাডি প্ল্যানার বা টু-ডু লিস্ট নেই।
- কোনো ক্লাউড ডাটাবেজ বা পাসওয়ার্ড সাইন-আপের ঝামেলা নেই; সবকিছু ব্রাউজারের `localStorage`-এ সুপারফাস্ট ও সিকিউর।

## 🚀 লোকাল ডেভেলপমেন্ট (Run Locally)

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# লোকাল সার্ভার চালু করুন
npm run dev

# ব্রাউজারে ওপেন করুন: http://localhost:3000
```

## 🌐 Vercel-এ ডিপ্লয়মেন্ট (1-Click Deployment)

1. রিপোজিটরিতে কোড পুশ করুন:
   ```bash
   git add .
   git commit -m "feat: upgrade AIBA Radar with luxury UI, faculty popover and smart major filter"
   git push origin main
   ```
2. [vercel.com](https://vercel.com)-এ গিয়ে **Add New Project** সিলেক্ট করে গিটহাব রিপোজিটরিটি ইমপোর্ট করুন।
3. Framework Preset: **Next.js** রেখে **Deploy** চাপুন।
